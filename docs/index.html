Quick start
1.

Start the server

Run opencode on your machine.

# without auth
opencode serve --port 4096

# with auth
OPENCODE_SERVER_PASSWORD=secret opencode serve --port 4096
2.

Connect from Spark

Open the app, go to settings, and enter your server details.

Host 192.168.1.100
Port 4096
Password your-password

For production setups with TLS, see the server guide.
