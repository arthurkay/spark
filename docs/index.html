Quick start

Get up and running in under 2 minutes.

1

Start the server

Run the opencode server on your machine. Optionally set a password for auth.

# Without auth
opencode serve --port 4096

# With auth
OPENCODE_SERVER_PASSWORD=secret opencode serve --port 4096
2

Open Spark on your phone

Install the app and tap Settings to add a new server connection.

3

Connect

Enter your server details:

Host: your-server-ip (e.g. 192.168.1.100)
Port: 4096
Password: your-secure-password

For production setups with reverse proxy and TLS, see the full server guide.
